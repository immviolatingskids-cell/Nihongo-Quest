# Nihongo Quest v0.9.6 — World Reactions & Environmental Cohesion

## Focused slice: deterministic reaction visibility

Sakura's existing event-driven reaction engine remains the single source of truth for answers, mistakes, quest/session boundaries, milestones, Garden growth, cultural discovery, and return visits. The shared presence surface now exposes the persisted canonical event as stable DOM metadata and announces the short contextual message through an accessible polite status region. This keeps reactions deterministic, saved, brief, and available on Home, Learn, Journey, Garden, Room, Shop, Journal, Progress, and Sakura surfaces without introducing another progression model.

The Sakura Horizon surface classes continue to provide shared card hierarchy, spacing, contrast, responsive composition, and reduced-motion behavior. Scene artwork remains owned by the existing registry and is mounted only for Room, Shop, and Garden; no new artwork or preload path was introduced.

## Compatibility and warnings

- No save fields changed; the existing `companionPresence.event`, reaction, message, timestamp, and seen-event count are reused.
- No Garden scoring, unlock threshold, cultural discovery, or ownership semantics changed.
- The existing nine-destination mobile navigation remains a v0.9.7 release-hardening item.
