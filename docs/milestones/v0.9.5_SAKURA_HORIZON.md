# Nihongo Quest v0.9.5 — Sakura Horizon

## Focused slice: Home and Journey direction

Home now leads with one recommendation derived from the existing `recommendNext()` engine. Resume behavior, curriculum progress, mastery, reviews, mistakes, Focus Quest sessions, daily quests, and weekly study days remain canonical; this slice adds no save fields or progression counters.

The welcome surface groups the learner's next action, progress summary, and three existing daily quest markers into a calm hierarchy. Focus Quest and quick practice remain available as lower-priority alternatives. Journey retains its existing deterministic map, node details, prerequisites, cultural discovery hooks, and session launch path while sharing the Sakura Horizon type, card, focus, spacing, and button language.

Responsive rules cover desktop, tablet, and approximately 390px mobile layouts. Primary actions become full-width on mobile, progress collapses to two columns, keyboard focus remains visible, companion artwork stays decorative to progression, and reduced-motion settings remove transitions.

## Compatibility and warnings

- No persisted state schema changed; legacy saves continue to merge through the existing state layer.
- No approved new Home or Journey environment artwork exists in the current asset catalogue, so this slice uses CSS atmosphere plus the approved Sakura companion image.
- The mobile navigation still contains the product's full existing destination set; a broader navigation audit is deferred to the v0.9.7 release-hardening pass.
