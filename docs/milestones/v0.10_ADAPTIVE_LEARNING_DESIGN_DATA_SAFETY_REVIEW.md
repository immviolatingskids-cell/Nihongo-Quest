# v0.10 — Adaptive Learning Design & Data-Safety Review

Status: approved review boundary; focused derived-support implementation complete.

## Purpose

The v0.9 foundation already has canonical mastery, due reviews, weak-word selection, answer history, Focus Quest sessions, Journey recommendations, and Garden progress. Any v0.10 support must improve the learner's next practice choice through those existing signals rather than create a parallel level, score, currency, or curriculum state.

## Proposed safe boundary

- Use only the existing local save data that already powers review and recommendations.
- Keep all support explainable in learner-facing language: show which existing signal caused a suggestion.
- Store no sensitive profile, inferred ability label, demographic attribute, or remote learner record.
- Make support reversible and optional; disabling it must leave canonical mastery and progression untouched.
- Preserve the existing deterministic recommendation and answer-recording boundaries until a separately approved implementation plan exists.
- Do not add adaptive content generation, curriculum expansion, NPC simulation, scarcity, or reward mechanics.

## Questions requiring explicit approval before implementation

1. Which existing signals may influence a recommendation, and which must remain presentation-only?
2. Is any new local preference permitted, or must support remain entirely derived from current state?
3. What learner-facing explanation and reset behavior is required for a changed recommendation?
4. What accessibility and reduced-motion expectations apply to adaptive prompts?

## Approved implementation slice

`adaptiveSupport()` derives a short explanation from the existing recommendation, due reviews, recent mistakes, saved session, time since study, and current chapter. Home presents that explanation beside the canonical next action. It is deterministic for the same current state, stores nothing, and cannot award XP, alter mastery, unlock content, or create a second progression model.

## Current decision

No adaptive fields, remote telemetry, or new progression state are introduced. This focused v0.10 slice is approved; broader personalization remains out of scope until a further design decision. v0.11 curriculum expansion and v0.12 hardening remain downstream milestones.
