# v0.11 — Japanese Expansion Curriculum Plan

Status: plan prepared; content implementation intentionally deferred pending approval.

## Product boundary

Japanese expansion must deepen learning inside the existing curriculum, Journey, mastery, review, Garden, cultural discovery, and companion systems. It must not create a second progression model, bypass prerequisites, or turn content breadth into a reward loop.

## Proposed curriculum shape

- Extend the canonical `curriculum` registry with a small, reviewed chapter set rather than creating a parallel catalogue.
- Reuse existing vocabulary, kana, grammar, conversation, `curriculumItems()`, `buildSession()`, and completion guards.
- Keep each new node bounded: one learner outcome, explicit prerequisite IDs, stable content IDs, answer alternatives, cultural context where relevant, and a clear estimated commitment.
- Add content in one approved thematic slice first, then validate mastery, review scheduling, Garden synchronization, cultural discovery eligibility, and Journey recommendation behavior before adding another slice.

## Content and safety review required before implementation

1. Approve the target theme, Japanese level, and learning outcomes.
2. Review every Japanese form, reading, translation, example, and accepted answer with a language-quality owner.
3. Confirm cultural notes and artwork references use approved sources and preserve discovery/ownership semantics.
4. Confirm the added content does not change existing unlock thresholds or saved progression meaning.
5. Define the regression fixture for legacy saves and the mobile/accessibility acceptance check.

## Current decision

No vocabulary, kana, grammar, scenario, curriculum node, unlock threshold, save field, or artwork is added by this plan. v0.11 implementation remains gated on approval of the theme and content review above.
