# Nihongo Quest v0.8A — Cultural Collection Foundation

v0.8A establishes the meaning and state model for a future Shop without turning Japanese culture into a loot economy.

## Registry and state

`src/cultural-items.js` is the authoritative catalogue. It currently contains 16 culturally grounded objects with Japanese text, reading, romaji, context, stable discovery/audio IDs, category, season, image slots, unlock hooks, and future home placement metadata. Fifteen approved production PNGs are integrated; the additional everyday-life entry retains the documented fallback slot. Save state stores only user-specific `culture.discovered`, `culture.owned`, `culture.acknowledged`, and visit data; metadata always derives from the registry.

Discovery and ownership are distinct and idempotent through `discoverItem`, `isDiscovered`, `acquireItem`, `isOwned`, and `canAcquire`. Acquisition is currently free after discovery, behind an economy-neutral interface. Invalid IDs fail safely and duplicates do not create repeated entries.

## Shop and Storekeeper

Shop is a first-class responsive destination. It offers a Storekeeper introduction, featured item, collection counts, placeholder-safe cards, discovery status, and free acquisition. Aoi-san is the stable Storekeeper identity: warm, patient, observant, knowledgeable, and gently humorous. Dialogue is grouped in `src/storekeeper.js`; Sakura remains the learning companion while Aoi-san remains the cultural guide.

## Journey and audio hooks

Each item carries a `discoveryId` and curriculum/milestone unlock reference for future meaningful Journey triggers. v0.8A provides the hooks and APIs; it does not invent unrelated discoveries or award culture for button presses. Cultural `audioId` values follow v0.7’s canonical audio service (`culture:<item-id>`), with no Shop-local speech synthesis.

## Art contracts and fallbacks

Item card art: 512×512 square source, transparent background, centred object, no text, consistent angle, safe padding. The approved files are transparent RGBA PNGs ranging from roughly 486–1254px and are preserved without material alteration; CSS containment handles their varied dimensions. Detail art may initially reuse the card source. Storekeeper art: transparent WebP/PNG bust, portrait crop, consistent margin, with neutral, welcoming, smiling, amused, thoughtful, proud, and surprised expressions. Future Shop environment art should support independent background, counter, and foreground layers and responsive crops. Until then, emoji/category placeholders preserve layout and accessibility; no broken image URLs are emitted.

## Persistence and accessibility

Legacy v0.7 saves merge into culture defaults. Export/import includes collection state; duplicate IDs are normalised and item metadata is never copied into saves. Shop cards expose text status and Japanese names; pronunciation continues through the v0.7 service. The layout uses stacked detail/content patterns suitable for mobile and remains usable without artwork.

## Reports and tests

Run `npm run culture:report` for registry, artwork, audio, placement, discovery-hook, and Storekeeper-art coverage. `validateCulturalItems()` checks IDs, required names, categories, discovery/audio formats, and placement metadata. Existing v0.3–v0.7 tests remain the regression suite; v0.8A tests should cover registry validation, idempotent discovery/acquisition, invalid IDs, legacy import/export, audio IDs, and Storekeeper dialogue groups.

## Known limitations and v0.8B

There is no final artwork, room editor, paid/random economy, seasonal event system, or automatic curriculum discovery wiring beyond the declared hooks. v0.8B can add proof assets, richer knowledge-card surfaces, explicit curriculum milestone mappings, and future Sakura-home placement while preserving this registry and save boundary.
