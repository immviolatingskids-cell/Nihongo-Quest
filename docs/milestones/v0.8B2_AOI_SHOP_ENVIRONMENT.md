# v0.8B.2 — Aoi's Shop Environment

v0.8B.2 completes the agreed three-asset visual threshold without expanding into a large bespoke environment system.

## Assets

- `assets/shop/aoi-shop-interior.png` is the approved 16:9 source interior. It contains no readable text or baked-in UI and is used through an optimized WebP derivative.
- `assets/shop/aoi-thoughtful.png` adds a distinct thoughtful pose and expression.
- `assets/shop/aoi-proud.png` adds a restrained proud/delighted pose and also serves the surprised semantic state.

The two portrait sources preserve Aoi's established silver bun, sakura ornaments, round glasses, plum kimono, navy apron, age, and facial identity. Their backgrounds are genuinely transparent after an alpha-channel verification. The earlier neutral, welcoming, and smiling portraits remain unchanged.

## Integration

The interior is a single responsive background layer on Aoi's introduction card, darkened by a CSS readability gradient. It does not block controls or require a separate counter layer. The seven semantic expression states now map to five distinct portrait assets: neutral, welcoming, smiling, thoughtful, and proud. Surprised deliberately reuses proud; amused deliberately reuses smiling.

PNG files remain source-of-truth assets. Quality-90 WebP derivatives preserve alpha and are the runtime files copied by the production build.

## Acceptance gate

v0.8B.2 passes when desktop and mobile visual inspection confirms readable content, safe crops, consistent Aoi identity, clean portrait edges, and an unobstructed Shop; the Culture report, automated tests, production build, syntax check, and diff check must also pass.
