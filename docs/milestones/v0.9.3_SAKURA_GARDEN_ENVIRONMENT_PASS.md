# v0.9.3 Sakura Garden Environment Pass

Status: integrated with the seven approved Garden source PNGs and optimized WebP runtime derivatives.

## Progress from the masterplan

The Garden now uses the canonical Living World scene boundary for its background and responsive crop. The old direct Garden background image was removed from the view so the scene registry is the single runtime owner and the same asset is not requested twice. Approved master, growth, light, petals and foreground layers are registered there; only the active growth overlay is mounted.

Visual mapping is deterministic and does not change canonical progression: levels 1–2 (Seed, Sprout) use Early; levels 3–4 (Young Tree, First Bloom) use Growing; levels 5–7 (Flourishing, Moonlit Garden, Full Bloom) use Full Bloom. Runtime order is master → active growth → lantern/light → petals → foliage foreground → future character slot → HTML UI.

Garden growth remains owned by `gardenProgress` in `src/engine.js`. Existing levels, thresholds, unlocks, milestones, recent-growth messages, persistence, and companion events are unchanged. The presentation layer only displays those derived values as HTML.

## Acceptance status

- Scene registry: complete for the approved layered Garden artwork.
- Foreground/depth capability: registered with a lower-right character-safe region and bounded depth displacement metadata.
- Ambient capability: approved petal/light layers use restrained CSS-first motion and reduced-motion suppression.
- Responsive behavior: existing desktop/tablet/mobile framing remains registered and is used by the Garden host.
- Accessibility: Garden state remains in the accessible section label, HTML caption, progress bar, and ledger; decorative art and future layers are nonessential.
- Conditional loading: the Garden background is applied only when the Garden view is mounted; optional layers load only when a source is present.
- Progression compatibility: no engine or save-schema changes.
- Artwork: integrated from `assets/garden/*.png`; WebP derivatives are checked in for runtime delivery and PNG sources remain preserved.

## Validation

Focused scene tests cover Garden growth compatibility, optional layer metadata, no-preload behavior, and the absence of a duplicate direct Garden image. The current automated gate is green: `npm test` passes 45/45, `npm run culture:report` reports 16 items with 15 illustrated and one intentional text-only entry, `npm run build` succeeds, and JavaScript syntax plus `git diff --check` pass. Fresh browser visual QA still needs to be run in an environment with the project preview host available; the Computer Use helper was unavailable in this run.
