# Nihongo Quest v0.9 — Cultural Discovery & Sakura's Room

## Learning-earned discovery

Cultural discoveries now resolve from the catalogue's existing curriculum and achievement unlock rules. The canonical completion paths call one idempotent synchronizer; opening a mystery card no longer creates progress. Existing saves are quietly backfilled on startup so eligible items appear without a burst of historical notifications.

Discovery, acknowledgement, ownership, and placement remain separate states. Opening a discovered knowledge card acknowledges it. Adding it to the collection grants ownership, and only owned objects may be placed.

## Interactive room

Sakura's Room uses a generated, text-free static background with an interactive HTML layer. Seven fixed responsive zones—window, shelf, desk, wall, low table, entrance, and floor—support the catalogue's placement metadata. Related source zones such as sitting/play and counter normalize to floor and desk. Each zone holds one item, replacement is explicit through the selector, and removal is always available.

The generated background is `assets/sakura-room.png`. Cultural objects remain independent transparent assets rather than being baked into the scene. This preserves responsiveness, stateful customization, accessible labels, and missing-image fallbacks.

## Accessibility and persistence

Every visual hotspot is a keyboard-operable button with a descriptive label. A complete text control list mirrors the scene and exposes the occupied item for each zone. Selecting a hotspot moves focus to its corresponding control. Mobile uses a taller crop and compact sprites without changing saved placement state.

Save schema v4 adds only `culture.placements`, a zone-to-item map. Legacy saves receive an empty map. Runtime projection ignores unknown, unowned, or zone-incompatible placement entries, so imports cannot render invalid room state.

## Journey and Shop integration

Journey node details preview whether a chapter contains a cultural discovery, while keeping the object mysterious until completion. Aoi-san's Shop only features genuinely discovered objects and directs an empty collection back to learning. Owned knowledge cards link directly to the room.

No currency, random reward, freeform dragging, scarcity, trading, or Garden decay is introduced.

## Verification gates

- Cultural discovery is progress-earned, idempotent, and acknowledgeable.
- Room placement requires ownership and enforces canonical zones.
- One item per zone replaces the previous item deterministically.
- Legacy saves migrate to schema v4 and invalid imported placement is ignored.
- The generated room asset is present and copied into the production build.
- Existing learning, audio, Garden, Journey, Shop, and companion tests remain green.
